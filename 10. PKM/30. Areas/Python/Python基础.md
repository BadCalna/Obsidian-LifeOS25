- **数据结构进阶：**
    - **列表 (Lists)**：有序、可变的数据集合，用 `[]` 定义。支持索引、切片、添加 (`append()`, `insert()`)、删除 (`del`, `remove()`, `pop()`) 等操作。
    - **元组 (Tuples)**：有序、**不可变**的数据集合，用 `()` 定义。支持索引和切片，但不能修改元素。常用于作为函数的多返回值或字典的键。
    - **字典 (Dictionaries)**：无序（Python 3.7+ 保持插入顺序）、可变的数据集合，以**键-值对**形式存储，用 `{}` 定义。键必须是**唯一且可哈希**的。支持通过键访问、添加/修改、删除。
    - **集合 (Sets)**：无序、可变的集合，**元素唯一**，用 `{}` 定义（空集合用 `set()`）。元素必须是**可哈希**的。支持添加 (`add()`)、删除 (`remove()`, `discard()`)，以及数学上的集合操作（并集 `|`, 交集 `&`, 差集 `-` 等）。
- **面向对象编程 (OOP)：**
    - **类 (Class)**：对象的蓝图或模板，定义了对象的属性（数据）和方法（行为）。
    - **对象 (Object/Instance)**：根据类创建的具体实体。
    - **`__init__` 方法**：构造方法，对象创建时自动调用，用于初始化对象的属性。`self` 参数指向当前实例。
    - **属性 (Attributes)**：对象的特征，是依附于对象的变量。
    - **方法 (Methods)**：对象的行为，是依附于对象的函数。
    - **继承 (Inheritance)**：允许子类复用、扩展或重写父类的属性和方法。`super().__init__()` 用于调用父类的构造方法。
	    - 为什么使用super()?而不直接使用父类.方法()？答案是：**Method Resolution Order (MRO) - 方法解析顺序**
		    - **处理复杂继承层次结构 (MRO)**：
				- Python 支持**多重继承**，即一个子类可以同时继承多个父类。
				- 当存在多重继承时，如果直接使用 `父类名.方法名(self, ...)`，你必须明确指定要调用哪个父类的方法。这在复杂的继承链（特别是**菱形继承**，即 A 继承自 B 和 C，然后 D 同时继承 B 和 C）中会变得非常混乱和容易出错。
				- `super()` 会根据 Python 的 **MRO (方法解析顺序)** 规则，自动找到正确的下一个要调用的方法。它确保在复杂的继承图中，每个父类的方法只被调用一次，并且按照正确的顺序。这避免了方法被重复执行或跳过，提高了代码的鲁棒性。
			- **更强的可维护性 (Less Coupling)**：
				- 使用 `super()` 时，你不需要明确地写出父类的名称。这意味着如果你将来改变了父类的名称，或者改变了类的继承结构，你不需要去修改子类中所有对 `super()` 的调用，代码的耦合度更低，更易于维护。
			- **更好的可读性**：
				- `super()` 明确表示你正在调用“当前对象的父类”的方法，这比直接写出具体父类名更具通用性，也更容易理解。
- **错误处理与异常：**
    - **异常 (Exceptions)**：程序运行时发生的、可被捕获和处理的问题。
    - **`try-except` 块**：用于捕获并处理异常，防止程序崩溃。可以有多个 `except` 块处理不同类型的异常。`else` 块在无异常时执行，`finally` 块无论有无异常都会执行。
    - **`raise` 语句**：用于主动抛出自定义或内置的异常。
- **模块与包：**
    - **模块 (Module)**：一个 `.py` 文件，包含 Python 代码，用于组织和重用功能。
    - **`import` 语句**：用于导入模块或模块中的特定功能 (`import module`, `import module as alias`, `from module import item`, `from module import *`)。
    - **包 (Package)**：一个包含多个模块和子包的目录，通常包含一个 `__init__.py` 文件（尽管 Python 3.3+ 不强制）。用于更复杂的代码组织。
- **文件操作：**
    - **`open()` 函数**：用于打开文件，返回文件对象。需要指定文件路径、模式（`'r'`, `'w'`, `'a'`, `'x'`, `'b'`, `'t'`）和编码。
    - **`close()` 方法**：关闭文件，释放资源。
    - **`with` 语句**：推荐的文件操作方式，确保文件在块结束时自动关闭。
    - **读取方法**：`read()`, `readline()`, `readlines()`, 迭代文件对象。
    - **写入方法**：`write()`, `writelines()`。
