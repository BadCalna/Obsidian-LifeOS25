## Learning with Gemini
---

- 想象一下，你要盖一栋房子。你可以从零开始，一块砖一块砖地垒，自己设计水电煤气，这当然可以，但效率会很低。Web框架就像是帮你预制好了一些房屋的骨架、水电管道和装修方案的工具箱。它提供了一系列工具和规范，让你能更快速、更高效地构建Web应用，而不需要每次都从最底层开始写代码。
- 为什么需要框架？
	1. **提高效率：** 框架提供了许多现成的组件和功能，比如路由、数据库操作、用户认证等，你不需要重复造轮子。
	2. **规范化：** 框架通常会强制或鼓励你遵循一定的开发模式，这使得代码结构更清晰，更易于维护和团队协作。
	3. **安全性：** 好的框架会内置一些安全机制，帮助你防御常见的Web攻击，比如SQL注入、跨站脚本攻击等。
	4. **社区支持：** 流行的框架通常拥有庞大的社区，遇到问题时可以很容易地找到帮助和资源。
### 常用框架
---
在Python中，最受欢迎的两个Web框架就是 **Flask** 和 **Django**。
- **Flask：** 它是一个“微框架”。它非常轻量级，核心功能很少，但提供了极高的灵活性。你可以根据项目需求自由选择和集成各种扩展。如果你的项目比较小，或者你更喜欢自己掌控一切，那么Flask会是一个很好的选择，它非常适合初学者快速上手。
- **Django：** 它是一个“全栈框架”。这意味着它包含了Web开发所需的大部分组件，从数据库ORM（对象关系映射）到管理后台、模板系统等等，都一应俱全。Django遵循“约定优于配置”的原则，能让你在短时间内快速开发出功能完善的大型应用。如果你的项目规模较大，或者需要快速搭建一个拥有完整功能的网站，Django会是更合适的选择。
> 可以把Flask想象成一套乐高积木，你可以用它搭建任何你想要的东西，但需要自己动手去组合。而Django则更像是一个精装修的公寓，所有基本设施都已为你准备好，你只需要搬进去就可以了。
