## **表单数据处理 (Form Handling)：**
### **后端接收用户输入**
- 在前端，我们使用 HTML 表单元素（如 `<input>`、`<textarea>`、`<select>` 等）来收集用户的输入。当用户提交表单时，这些数据就会被打包发送到后端服务器。后端的工作就是接收这些数据，然后进行处理（比如保存到数据库，或者根据输入执行特定逻辑）。
- 在 Flask 中，处理表单数据主要依赖于 Flask 提供的 `request` 对象。这个 `request` 对象包含了当前客户端发送过来的所有请求信息，包括表单数据、URL 参数、HTTP 头等等。
### **GET 请求与 POST 请求中的数据获取**
---
#### Get请求
-  数据会作为 URL 的一部分发送，通常在问号 `?` 后面以键值对的形式出现，比如 `example.com/search?query=python&page=1`。
- 这种方式适用于获取数据或进行搜索，数据量小且不敏感。
- 在 Flask 中，你可以通过 `request.args.get('键名')` 来获取 GET 请求的参数。
#### POST 请求
- 数据通常包含在 HTTP 请求的**请求体 (request body)** 中，用户在浏览器中是看不到的。
- 适用于提交敏感或大量数据，比如注册、登录、发布文章等。
- 在 Flask 中，你可以通过 `request.form.get('键名')` 来获取 POST 请求的表单数据。
### 一个示例
---
### **实战演练：一个简单的登录表单**
让我们来创建一个简单的登录页面，让你亲手体验如何处理 POST 请求的表单数据。
**第一步：修改 `app.py`**
我们需要导入 `request` 对象，并修改 `home` 路由，让它能够处理 GET 和 POST 请求。
```python
from flask import Flask, render_template, request # 导入 request 对象

app = Flask(__name__)

@app.route('/')
def welcome_page():
    return "欢迎来到我们的网站！访问 /login 来登录。"

@app.route('/login', methods=['GET', 'POST']) # 允许 GET 和 POST 请求
def login():
    if request.method == 'POST':
        # 如果是 POST 请求，说明用户提交了表单
        username = request.form.get('username') # 获取名为 'username' 的输入
        password = request.form.get('password') # 获取名为 'password' 的输入

        if username == 'admin' and password == 'password123': # 简单验证
            return render_template('dashboard.html', user=username) # 登录成功，渲染新页面
        else:
            # 登录失败，重新渲染登录页面并显示错误信息
            return render_template('login.html', error='用户名或密码错误')
    else:
        # 如果是 GET 请求，说明用户只是想访问登录页面
        return render_template('login.html') # 渲染登录页面

# 之前的路由保持不变，但为了简洁，这里省略了
@app.route('/greet')
def greet():
    return 'Hello, PyMaster!'

@app.route('/user/<name>')
def show_user_profile(name):
    return f'Hello, {name}!'

if __name__ == '__main__':
    app.run(debug=True)
```
> [!INFO] 
> ## **代码解释**
- `@app.route('/login', methods=['GET', 'POST'])`：**关键**！我们明确告诉 Flask，`/login` 这个 URL 路径可以接收 GET 和 POST 两种请求方法。
- `if request.method == 'POST':`：判断当前的请求是不是 POST 请求。
- `username = request.form.get('username')`：从 `request.form` 中获取表单里 `name="username"` 的输入值。`.get()` 方法的好处是如果键不存在，它会返回 `None` 而不是抛出错误。
- 我们进行了一个简单的用户名和密码验证，如果是 `admin` 和 `password123` 就认为是成功。
- `render_template('dashboard.html', user=username)`：如果登录成功，我们渲染一个名为 `dashboard.html` 的新模板，并将用户名作为 `user` 变量传递过去。
- `render_template('login.html', error='用户名或密码错误')`：如果登录失败，我们重新渲染 `login.html` 模板，并传递一个 `error` 消息，让模板显示错误信息。
