### **HTML：网页的骨架**
---
想象一下盖房子，**HTML (HyperText Markup Language)** 就是这栋房子的**骨架**。它定义了网页的结构和内容，告诉浏览器哪里是标题、哪里是段落、哪里是图片，以及哪里是链接等等。HTML 不是一门编程语言，而是一种**标记语言**，它使用一系列的“标签”来定义网页上的元素。
每个 HTML 标签通常都是成对出现的，像这样：`<tagname>内容</tagname>`。开始标签和结束标签包裹着内容。当然，也有一些是自闭合标签，比如图片标签。
- 以下是代码示例
```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>欢迎来到我的主页！</h1>
    <p>这是一个段落。</p>
    <img src="https://via.placeholder.com/150" alt="占位符图片">
    <a href="https://www.google.com">访问谷歌</a>
</body>
</html>
```
### **代码解释与常用标签示例**
- `<!DOCTYPE html>`: 这不是一个 HTML 标签，而是文档类型声明，告诉浏览器这是一个 HTML5 文档。
- `<html>`: 网页的根元素，所有其他内容都在它里面。
- `<head>`: 头部区域，包含页面的元信息，比如字符集、页面标题等，这些内容不会直接显示在网页上。
    - `<meta charset="utf-8">`: 定义了页面的字符编码为 UTF-8，这样可以正确显示各种语言文字。
    - `<title>我的第一个网页</title>`: 定义了浏览器标签页上显示的标题。
- `<body>`: 主体区域，包含所有可见的网页内容，比如文本、图片、链接等。
    - `<h1>` 到 `<h6>`: **标题标签**。`<h1>` 是最重要的标题，`<h6>` 是最不重要的。它们让你的内容有清晰的层级结构。
    - `<p>`: **段落标签**。用于包裹一段普通的文本。
    - `<img>`: **图片标签**（自闭合标签）。用于在网页中嵌入图片。
        - `src`: **图片源路径**。这是必须的属性，指向图片的地址。
        - `alt`: **替代文本**。当图片无法加载时显示，也对屏幕阅读器和SEO很重要。
    - `<a>`: **超链接标签**。用于创建从一个页面到另一个页面的链接。
        - `href`: **链接地址**。这是必须的属性，指向链接的目标URL。
