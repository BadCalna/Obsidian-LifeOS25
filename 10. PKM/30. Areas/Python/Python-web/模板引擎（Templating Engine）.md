### **模板引擎：后端与前端的“桥梁”**
---
还记得我们 Flask 的“Hello World”和动态路由吗？视图函数直接返回了一个字符串，比如 `return 'Hello, World!'` 或者 `return f'Hello, {name}!'`。但真实的网页可不是只有一两行字符串那么简单，它们是复杂的 HTML 文件，里面还嵌着 CSS 和 JavaScript！
如果每次都要在 Python 代码里用字符串拼接的方式来生成整个 HTML 页面，那简直是噩梦！代码会变得非常混乱，而且修改一点样式或结构都得去改 Python 后端代码，这效率也太低了。
这就是**模板引擎**的用武之地了。
**模板引擎**就像一个“填空表格生成器”。它允许你创建带有**占位符**的 HTML 文件（我们称之为**模板**）。后端（比如 Flask）会把动态的数据（比如用户名、文章列表、商品价格等）传递给这个模板引擎，然后模板引擎就会用这些数据去**填充**模板中的占位符，最终生成一个完整的、个性化的 HTML 页面，再发送给浏览器。
> 在 Flask 中，默认使用的模板引擎是 **Jinja2**。它非常强大且易于使用，语法和 Python 有些相似。
- 详见[[Jinjia2基础]]
- 实践时，Flask应用会在你的应用根目录下寻找一个名为 `templates` 的文件夹来存放模板文件。
	- 然后在 `templates` 文件夹内，创建一个名为 `index.html` 的文件
	- 最后在Flask 中导入 `render_template` 函数，然后让视图函数返回渲染后的模板，并传递数据进去。
