### **后端开发基础：路由（Routing）的深度解析**
还记得我们 Flask 的 "Hello World" 应用吗？
```python
@app.route('/')
def hello_world():
    return 'Hello, World!'
```
- 这里的 `@app.route('/')` 就是一个**路由装饰器**。简单来说，**路由（Routing**）就是定义了当用户访问某个特定的 URL (比如 `/` 或 `/greet`) 时，你的 Flask 应用应该执行哪个 Python 函数。它就像一个“交通指挥官”，将传入的网络请求导向正确的处理代码。
- 每一个被 `@app.route()` 装饰的函数，我们都称之为**视图函数（View Function）**。视图函数接收 Web 请求，处理逻辑（比如从数据库获取数据），然后返回一个响应（比如一个 HTML 页面、一段文本或 JSON 数据）给用户的浏览器。
#### 路由的强大之处
路由不仅仅是匹配一个固定的 URL。它还可以：
1. **处理不同的 HTTP 方法：** 网页请求不仅仅是访问，还有提交表单（POST）、更新数据（PUT）等。路由可以指定视图函数只响应特定的 HTTP 方法。
    - 例如：`@app.route('/login', methods=['GET', 'POST'])` 表示 `/login` 路径可以处理 GET 和 POST 请求。GET 请求通常用于显示页面，POST 请求用于提交数据。
2. **接受动态 URL 参数：** 你可以定义带有变量的 URL 路径，这样同一个视图函数就可以处理不同数据的请求。
    - 例如：你想显示不同用户的个人资料，URL 可能是 `/user/123` 或 `/user/john_doe`。
    - 在 Flask 中，你可以这样定义：`@app.route('/user/<username>')` 或 `@app.route('/post/<int:post_id>')`。尖括号 `< >` 内就是**变量名**，冒号 `:` 前面是变量的类型转换器（比如 `int` 表示整数）。
