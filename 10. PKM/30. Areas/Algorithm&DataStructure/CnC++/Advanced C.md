## **指针：变量的“地址”**
- 首先，我们来理解什么是内存地址。
- 你平时用变量存储数据，比如 int num = 10;。计算机在内部会为这个变量 num 在内存中分配一块空间，并把 10 存储进去。这块内存空间就像你家里的一个房间，它有一个唯一的地址（比如门牌号），你可以通过这个地址找到这个房间。
- **指针** (Pointer)，顾名思其义，就是“指向”内存地址的变量。它存储的不是数据本身，而是数据所在内存的地址。可以把指针想象成一个“门牌号”，通过这个门牌号，你就能找到对应的房间（内存空间）和房间里的“住户”（数据）。
### 指针的声明与初始化
- 声明指针时，需要指定它将指向什么类型的数据，并在变量名前加上 *。
- 语法： 数据类型 *指针变量名;
- 例子：
```c
int num = 10;     // 声明一个整型变量 num，值为 10
int *ptr;         // 声明一个指向整型的指针变量 ptr
                  // 此时 ptr 还没有指向任何有效的地址，被称为“野指针”，非常危险！

ptr = &num;       // 初始化指针：将 num 变量的内存地址赋值给 ptr
                  // `&` 是“取地址运算符”，它会返回变量的内存地址
```
### 指针的解引用
- 一旦指针指向了一个有效的地址，你就可以通过它来**访问或修改**该地址上的数据。这个操作叫做**解引用 (Dereferencing)**，使用 `*` 运算符。
- **语法：** `*指针变量名`
- **例子：**
```c
printf("num 的值是：%d\n", num);      // 输出：num 的值是：10
printf("ptr 存储的地址是：%p\n", ptr);  // 输出：ptr 存储的地址是：(一个十六进制地址，例如 0x7ffee5d0)
printf("通过 ptr 解引用得到的值是：%d\n", *ptr); // 输出：通过 ptr 解引用得到的值是：10

*ptr = 20; // 通过指针解引用来修改 num 的值
printf("修改后，num 的值是：%d\n", num); // 输出：修改后，num 的值是：20
```
### 指针与函数参数传递：传址调用 (Call by Reference)
```c
void increment(int *p) { // 函数接收一个指向整型的指针
    (*p)++;               // 解引用指针 p，然后对它指向的值进行自增操作
    printf("在函数内部，*p 的值是：%d\n", *p);
}

int main() {
    int value = 10;
    printf("调用函数前，value 的值是：%d\n", value); // 输出：10
    increment(&value); // 传入 value 变量的地址
    printf("调用函数后，value 的值是：%d\n", value); // 输出：11 (值被成功修改了！)
    return 0;
}
```

## 结构体&联合体
---
- 结构体就是一个**自定义数据类型**
	- Python里面那些便捷的类型（string, bool……）估计底层是通过结构体实现的
- 在 C 语言中，我们有像 `int`、`float`、`char` 这样的基本数据类型。但很多时候，我们需要把不同类型的数据组合在一起，来描述一个更复杂的实体。比如，你想描述一个“学生”，它可能包含姓名（字符串）、年龄（整数）、学号（整数）和分数（浮点数）。
- 这时候，**结构体 (struct)** 就派上用场了！结构体允许你把不同类型的数据项组合成一个单一的复合数据类型。你可以把它想象成一个“自定义的蓝图”或“模板”，你可以用这个模板来创建很多拥有相同属性的“对象”。
### 定义结构体
使用 `struct` 关键字来定义结构体。
```c
struct Student {
    char name[50]; // 姓名 (用字符数组表示字符串)
    int age;       // 年龄
    int student_id; // 学号
    float score;   // 分数
}; // 别忘了分号！
```
### 声明和使用结构体变量
- 声明示例
```c
struct Student student1; // 声明一个名为 student1 的 Student 类型变量

// 访问结构体成员使用点运算符 '.'
strcpy(student1.name, "张三"); // 为姓名赋值 (注意字符串赋值需要用 strcpy 函数)
student1.age = 20;
student1.student_id = 1001;
student1.score = 92.5;

printf("学生姓名: %s, 年龄: %d, 学号: %d, 分数: %.1f\n",
       student1.name, student1.age, student1.student_id, student1.score);
```
>这里 `strcpy` 是一个字符串拷贝函数，你需要 `#include <string.h>` 来使用它。因为 C 语言的字符串是字符数组，不能直接用 🟰 赋值。
### 结构体指针
- 就像普通变量可以有指针一样，结构体变量也可以有指针。当使用结构体指针访问其成员时，需要使用**箭头运算符 `->`**。
- 示例
```c
struct Student student2; // 声明一个 Student 变量
struct Student *ptr_student; // 声明一个指向 Student 结构体的指针

ptr_student = &student2; // 将 student2 的地址赋给指针

// 通过指针访问结构体成员，使用 -> 运算符
strcpy(ptr_student->name, "李四"); // 等价于 (*ptr_student).name
ptr_student->age = 22;             // 等价于 (*ptr_student).age
ptr_student->student_id = 1002;
ptr_student->score = 88.0;

printf("通过指针访问的学生姓名: %s, 年龄: %d\n",
       ptr_student->name, ptr_student->age);
```
### 联合体
- **联合体 (union)** 也是一种自定义数据类型，它和结构体很相似，但有一个关键区别：**联合体的所有成员共享同一块内存空间**。这意味着，在任何时候，联合体中只有一个成员可以存储有效值。
```c
union Data {
    int i;
    float f;
    char str[20];
};

union Data data1;

data1.i = 10;
printf("data1.i: %d\n", data1.i); // 输出：10

data1.f = 22.5;
printf("data1.f: %.1f\n", data1.f); // 输出：22.5
// 此时 data1.i 的值可能已经损坏，因为它和 f 共享内存

strcpy(data1.str, "Hello Union");
printf("data1.str: %s\n", data1.str); // 输出：Hello Union
// 此时 data1.i 和 data1.f 的值也可能已经损坏
```
> 联合体通常用于节省内存，或者当你确定在某个时刻只需要使用某个数据类型的场景。因为它们共享内存，所以在使用时要特别小心，避免数据混淆。

## 动态内存管理
- 无论是 int num = 10; 还是 struct Student student1;，这些变量的内存空间都是在程序编译时或进入函数时就确定并分配好的。这种内存分配方式叫做静态内存分配或栈上分配。
- 但很多时候，我们无法预知程序运行时需要多少内存。比如，你写一个程序来存储用户输入的数据，用户可能输入10个，也可能输入1000个。这时，如果提前分配一个固定大小的内存，就可能造成浪费（分配太多）或者不够用（分配太少）。
- 动态内存管理就解决了这个问题。它允许你在程序运行时根据需要，从一块叫做堆区（Heap）的内存区域申请内存空间，并在不需要时将其释放。这就像你在图书馆借阅书籍，需要时去借，看完后归还，而不是一开始就买下所有可能的书籍。
