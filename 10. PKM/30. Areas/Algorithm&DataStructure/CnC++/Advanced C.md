## **指针：变量的“地址”**
- 首先，我们来理解什么是内存地址。
- 你平时用变量存储数据，比如 int num = 10;。计算机在内部会为这个变量 num 在内存中分配一块空间，并把 10 存储进去。这块内存空间就像你家里的一个房间，它有一个唯一的地址（比如门牌号），你可以通过这个地址找到这个房间。
- **指针** (Pointer)，顾名思其义，就是“指向”内存地址的变量。它存储的不是数据本身，而是数据所在内存的地址。可以把指针想象成一个“门牌号”，通过这个门牌号，你就能找到对应的房间（内存空间）和房间里的“住户”（数据）。
### 指针的声明与初始化
- 声明指针时，需要指定它将指向什么类型的数据，并在变量名前加上 *。
- 语法： 数据类型 *指针变量名;
- 例子：
```c
int num = 10;     // 声明一个整型变量 num，值为 10
int *ptr;         // 声明一个指向整型的指针变量 ptr
                  // 此时 ptr 还没有指向任何有效的地址，被称为“野指针”，非常危险！

ptr = &num;       // 初始化指针：将 num 变量的内存地址赋值给 ptr
                  // `&` 是“取地址运算符”，它会返回变量的内存地址
```
### 指针的解引用
- 一旦指针指向了一个有效的地址，你就可以通过它来**访问或修改**该地址上的数据。这个操作叫做**解引用 (Dereferencing)**，使用 `*` 运算符。
- **语法：** `*指针变量名`
- **例子：**
```c
printf("num 的值是：%d\n", num);      // 输出：num 的值是：10
printf("ptr 存储的地址是：%p\n", ptr);  // 输出：ptr 存储的地址是：(一个十六进制地址，例如 0x7ffee5d0)
printf("通过 ptr 解引用得到的值是：%d\n", *ptr); // 输出：通过 ptr 解引用得到的值是：10

*ptr = 20; // 通过指针解引用来修改 num 的值
printf("修改后，num 的值是：%d\n", num); // 输出：修改后，num 的值是：20
```
### 指针与函数参数传递：传址调用 (Call by Reference)
```c
void increment(int *p) { // 函数接收一个指向整型的指针
    (*p)++;               // 解引用指针 p，然后对它指向的值进行自增操作
    printf("在函数内部，*p 的值是：%d\n", *p);
}

int main() {
    int value = 10;
    printf("调用函数前，value 的值是：%d\n", value); // 输出：10
    increment(&value); // 传入 value 变量的地址
    printf("调用函数后，value 的值是：%d\n", value); // 输出：11 (值被成功修改了！)
    return 0;
}
```
