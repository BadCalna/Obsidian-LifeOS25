- 起源与诞生
	- C 语言诞生于 20 世纪 70 年代初的贝尔实验室，由丹尼斯·里奇 (Dennis Ritchie) 在开发 UNIX 操作系统时设计。它的出现极大地推动了操作系统的发展，因为 C 语言结合了汇编语言的高效率和高级语言的易读性。
- **C 语言的特点：**
	- **高效和强大：** C 语言可以直接访问内存，这让它在处理底层任务时非常高效，比如操作系统、驱动程序和嵌入式系统开发。    
	- **可移植性强：** 用 C 语言编写的程序，只要稍作修改或不修改，就能在不同的硬件和操作系统上编译运行。这就像是编写了一份“通用食谱”，大多数厨房都能照着做出来。
	- **语法简洁：** 它的语法相对简单，没有太多复杂的特性，这使得它易于学习和理解。
	- **面向过程：** C 语言主要是面向过程的，这意味着程序被组织成一系列的函数调用，每个函数执行一个特定的任务。
## **数据类型、变量、常量、运算符
---
### 数据类型(Data Types)
- **数据类型**告诉编译器变量将存储哪种类型的值。这就像是你要把水装进杯子，把面粉装进袋子，你不能把水装进袋子里，因为它们需要的“容器”不同。
- C 语言有几种基本的数据类型：
- **整型 (Integers):** 用来存储整数，比如 `5`、`-100`。
    - `int`: 最常用的整型，通常占用 4 个字节。
    - `short`: 短整型，占用 2 个字节，范围较小。
    - `long`: 长整型，占用 4 或 8 个字节，范围较大。
    - `long long`: 更长的整型，占用 8 个字节，范围最大。
    - 你还可以在前面加上 `unsigned` 关键字，表示只存储非负数，这样能扩大正数的存储范围。
- **浮点型 (Floating-Point Types):** 用来存储带小数的数字，比如 `3.14`、`-0.5`。
    - `float`: 单精度浮点型，占用 4 个字节。
    - `double`: 双精度浮点型，占用 8 个字节，精度更高，通常更推荐使用。
- **字符型 (Character Type):** 用来存储单个字符，比如 `'A'`、`'z'`、`'7'`。
    - `char`: 占用 1 个字节，可以存储 ASCII 码中的任何字符
- 不同数据类型占据的内存大小，可以通过 `sizeof` 运算符来查看，这在不同系统上可能会有所差异。
### 变量 (Variables)
- **变量**是用来存储数据的地方。你可以把它想象成一个贴有标签的盒子，标签上写着变量的名字，盒子里装着它的值。而且，这个盒子里装的东西是可以改变的（所以才叫“变量”）。
- **声明变量的语法：** `数据类型 变量名;`
- **初始化变量的语法：** `数据类型 变量名 = 初始值;`
### 常量 (Constants)
- **常量**是程序中值不能被改变的数据。一旦你给常量赋值了，它就不能再变了。这就像食谱里的“盐”的用量，通常是固定不变的。
- 有两种常见的定义常量的方式：
	- 使用 `#define` 预处理指令：    
    ```C
    #define PI 3.14159 // 定义一个宏常量 PI
    ```
- 使用 `const` 关键字：    
	```C
    const int MAX_SCORE = 100; // 定义一个整型常量 MAX_SCORE
    ```
    通常更推荐使用 `const` 关键字，因为它提供了更好的类型检查。
### 运算符 (Operators)
**运算符**是用来对变量和常量进行操作的符号。它们能让你执行各种计算和逻辑判断。
C 语言中的主要运算符类别：
- **算术运算符:** `+` (加), `-` (减), `*` (乘), `/` (除), `%` (取模，即取余数)
    - 例子：`int result = 10 / 3; // result 将是 3`
    - 例子：`int remainder = 10 % 3; // remainder 将是 1`
- **关系运算符:** 用来比较两个值，结果是真 (`1`) 或假 (`0`)。
    - 例如== (等于), `!=` (不等于), `>` (大于), `<` (小于), `>=` (大于等于), `<=` (小于等于)
    - 例子：`bool is_equal = (5 == 5); // is_equal 为真 (1)`
- **逻辑运算符:** 用来组合或修改布尔表达式。
    - `&&` (逻辑与), `||` (逻辑或), `!` (逻辑非)
    - 例子：`if (age > 18 && has_license) { /* ... */ }`
- **位运算符:** 对二进制位进行操作，通常在底层编程中用到。
    - `&` (按位与), `|` (按位或), `^` (按位异或), `~` (按位非), `<<` (左移), `>>` (右移)
- **赋值运算符:** 用来给变量赋值。
    - = (赋值), `+=` (加等于), `-=` (减等于), `*=` (乘等于), `/=` (除等于), `%=` (模等于)
    - 例子：`int x = 5; x += 3; // x 现在是 8`        
- **自增/自减运算符:** `++` (自增), `--` (自减)
    - `x++` (后置自增，先使用 x 的值，再将 x 加 1)
    - `++x` (前置自增，先将 x 加 1，再使用 x 的值)
理解这些基本概念是 C 语言编程的基础。它们就像是你学习数学时的数字、符号和方程式，掌握了它们才能进行更复杂的计算。
### 条件语句
- **`if`, `else if`, `else`：** 这是最基本的条件判断，就像你在做选择题。
```c
int score = 85;
if (score >= 90) {
    printf("A 优\n");
} else if (score >= 80) { // 如果上面条件不满足，再判断这个
    printf("B 良\n");
} else if (score >= 60) {
    printf("C 及格\n");
} else { // 如果以上所有条件都不满足
    printf("D 不及格\n");
}
```
- **`switch`：** 当你需要根据一个变量的不同值来执行不同操作时，`switch` 语句会比一长串 `if-else if` 更清晰、更高效。
```c
char grade = 'B';

switch (grade) {
    case 'A':
        printf("优秀！\n");
        break; // 跳出 switch 语句
    case 'B':
        printf("良好！\n");
        break;
    case 'C':
        printf("及格。\n");
        break;
    default: // 如果所有 case 都不匹配
        printf("需要努力。\n");
        break;
}
```
- `switch` 语句特别适用于处理枚举类型或少量离散的整数/字符值。记住，每个 `case` 后面通常都要加上 `break;`，否则程序会继续执行下一个 `case` 的代码（这叫“穿透”，有时候有用，但大部分时间会是 Bug！）。
### 循环语句
- **`for` 循环：** 当你知道循环需要执行的次数时，`for` 循环是最好的选择。它通常用于迭代序列，比如数组
```c
// 打印从 1 到 5 的数字
for (int i = 1; i <= 5; i++) {
    printf("%d ", i); // 输出：1 2 3 4 5
}
printf("\n");
```
- `for` 循环的括号里有三部分，用分号 `;` 分隔
	1. **初始化：** 循环开始前执行一次（例如 `int i = 1;`）。
	2. **条件：** 每次循环开始前检查，如果为真则继续执行（例如 `i <= 5;`）。
	3. **更新：** 每次循环体执行完后执行（例如 `i++;`）。
- **`while` 循环：** 当你不确定循环会执行多少次，但知道循环的结束条件时，`while` 循环很合适。
```c
int count = 0;
while (count < 3) {
    printf("Count is: %d\n", count);
    count++;
}
// 输出：
// Count is: 0
// Count is: 1
// Count is: 2
```
只要 `while` 后面的条件为真，循环就会一直执行。
- **`do-while` 循环：** 和 `while` 循环类似，但 `do-while` 循环会**至少执行一次**循环体，然后才检查条件。
```c
int num = 0;
do {
    printf("Enter a number (0 to exit): ");
    scanf("%d", &num); // 读取用户输入的数字
    printf("You entered: %d\n", num);
} while (num != 0); // 如果输入不是 0，则继续循环
```
#### 输入输出函数
---
**基本语法：** `printf("格式控制字符串", 表达式1, 表达式2, ...);`
- **格式控制字符串：** 这是一个包含普通文本和**格式说明符**的字符串。
    - **普通文本**会原样输出。
    - **格式说明符**是特殊的占位符，告诉 `printf` 如何解释并显示后面的变量值。它们总是以 `%` 开头。
- **表达式/变量列表：** 对应于格式说明符的变量或表达式。
**常用的格式说明符：**
- `%d` 或 `%i`: 输出整数 (int)
- `%f`: 输出浮点数 (float, double)
- `%lf`: 特别用于 `scanf` 读取 `double`，但在 `printf` 中 `%f` 也能用于 `double`
- `%c`: 输出单个字符 (char)
- `%s`: 输出字符串 (字符数组)
- `%p`: 输出指针地址
- `%x` 或 `%X`: 输出十六进制数
- `%o`: 输出八进制数
- `%%`: 输出百分号 `%`
